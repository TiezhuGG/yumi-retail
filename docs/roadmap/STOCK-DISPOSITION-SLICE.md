# 报损与数量隔离切片 · 2026-10-28

范围：本仓已有批次位置的整数数量隔离，立即增加blocked、可售相应减少、实物总数不变；解除/报损通过DRAFT→APPROVED→POSTED，可在过账前CANCELLED。隔离保留原库位，不实现实体隔离区移位、退货、自动效期任务或成本会计。

开发默认：管理员/仓管隔离、申请处置、取消与过账；审批须另一员工。立即隔离不等待审批，避免问题库存继续售卖。解除必须重新确认未过期及库位启用；报损只处理指定隔离记录的剩余数量，须过账时明确提交实物报损核验说明。待审批草稿不预扣隔离额度，界面说明其不是已完成处置。

所有数量动作先锁仓库SKU余额，检查仓库授权、盘点冻结、核对暂停及账本一致，再复核位置/隔离版本。隔离最多自由数量onHand-reserved-blocked；解除只减blocked；报损同时减onHand和blocked，reserved不变。不能用报损替代库存账本修复，不能直接报损可售数。快照过期不能覆盖，须取消重建；取消不解隔离、不改数、不释放其他暂停。

每动作持久化幂等、审计和新两级流水，原流水不改。隔离剩余=原数量−已过账处置之和，数据库配平/非负/复合外键与不可变约束保护事实。过期可隔离报损，拒绝解除；有预占时仅隔离其余自由数，不扣预占。

验收：隔离可售变化、解除/报损完整闭环、独立审批、过期/停用/跨仓/骑手/CSRF/非法数拒绝、冻结冲突、版本冲突、20次重试和不同键竞争、晚期失败原子回滚、取消保留隔离、隔离剩余额度及两级账本一致；真实PostgreSQL一次性schema。后台/H5浏览器使用合成数据演示，真机/实物不宣称通过。
