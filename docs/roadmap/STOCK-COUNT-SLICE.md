# 单SKU实物盘点切片 · 2026-10-28

范围：一个已存在库存的仓库/SKU，冻结全部现有批次位置（最多200个，超限拒绝），冻结快照→一次性录入全部实盘数→提交→审批→事务过账；终态前可带原因终止。无多SKU盘点、未知批次盘盈、报损、自动到期解冻。

开发默认规则，正式经营分权仍待确认：管理员/仓管可发起，仅发起人录入并提交，审批必须由另一位具备审批权限的员工完成；过账可由具备过账权限的员工执行。冻结前账本必须一致、没有核对暂停、没有预占。冻结期间公开可售0，收货及移位拒绝；未来预占/出库必须遵守相同余额锁与冻结检查。

实盘是各位置总实物数（含blocked），不得小于预占+blocked；过期批次允许盘点，仍不可售。提交后不可修改，审批/过账前复核快照与账本；发现冲突保留冻结并要求人工终止/排查，不覆盖新版本。过账新建差异主流水和位置流水，数量缓存、单据、审计、幂等记录与释放冻结同事务；零差异不制造数量流水。核对暂停与盘点冻结独立，终止/过账不清除核对暂停；终止若新发现账本差异，保存报告并设置核对暂停。

验收：冻结/终止不改数；少行/重复/负数/低于保护数拒绝；独立审批；相同意图重试和不同意图竞争；入库/移位竞争与公开不可售；盘盈盘亏及零差异账本一致；后半事务失败完全回滚；跨仓/角色/旧版本/不可变快照拒绝；全部使用一次性PostgreSQL测试schema。Web/H5提供相同动作，浏览器和真机结果分别记录。
