## 设计取舍与竞品参考

- 消费者端用玉米黄、奶白和暖灰搭配日用品摄影。把积分余额、明细和兑换订单放在易发现的位置，并用固定底部操作区域承接详情和确认。参考有赞的积分中心入口、兑换记录与配货打印设计思路。[有赞积分中心](https://help.youzan.com/displaylist/detail_4_4-1-22002) · [有赞兑换记录](https://help.youzan.com/displaylist/detail_4_4-1-77733) · [有赞配货打印](https://help.youzan.com/displaylist/detail_5_5-2-33381)
- 后台用深橄榄侧栏和浅灰工作区，表格适合快速筛选，详情与时间线承接证据。库存按仓库、库位、批次和变动来源追溯，盘点单独呈现实盘与复核。参考 Square 的库存历史与盘点流程。[Square 库存变动](https://squareup.com/help/us/en/article/6061-view-stock-adjustment-history-with-square-for-retail) · [Square 盘点](https://squareup.com/help/us/en/article/8249-conduct-full-inventory-counts-with-square-for-retail)
- 仓库移动端用浅苔绿突出库位、件数和核对进度，骑手端用浅蓝区分自己的任务，并把地址、件数和当前阶段操作放到首屏。配送状态和工作队列参考 Shopify POS 的本地配送管理。[Shopify POS 本地配送](https://help.shopify.com/en/manual/sell-in-person/shopify-pos/order-management/local-delivery-orders)

## 文件与检查

- `png/` 按角色存放原图。手机以 390 CSS px 导出，桌面以 1440 CSS px 导出，长页面按内容全高导出。
- `screens.js` 保存页面目录和示例内容，`preview.js` 与 `style.css` 保存预览与样式，`assets/` 保存原创生成的摄影素材。图集使用浏览器渲染可读中文、表格、规格及金额。
- `export.cjs` 使用项目已有的本地 Playwright 或通过 `YUMI_PLAYWRIGHT_PATH` 指定的 Playwright。可选用 `YUMI_CHROME_PATH` 指向本机 Chrome，然后执行 `node docs/design/yumi-ui-atlas/export.cjs`。
- 浏览器检查逐页标题、图集与原图对应关系、内部链接和横向溢出，并验证积分兑换后取消、人工快递、运单更正、售后反馈、拣货核对和骑手异常的预览跳转。
- 这是使用合成商品、地址和账务数据的设计稿。配货预览可以调用浏览器的样例打印。筛选、真实单据写入、正式打印和支付由后续工程集成实现或复用。业务接口、微信真机、实际打印和生产环境按独立验收流程核验。
