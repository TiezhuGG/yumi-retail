# 合成异常清单筛选与待处置概览 · 2026-11-02

本轮完成配送列表的全部/待处置/已处置/无异常筛选、全范围互斥总数、读取时间、异常原因标识及详情返回后保留筛选。仅只读查询，无新模型、迁移、写入权限或业务状态变化。

GET /api/v1/delivery-lab?warehouseId=…新增可选exceptionState=ALL|OPEN|RESOLVED|NONE，默认ALL；严格拒绝无效类型/枚举及重复参数。OPEN指已有异常但无处置凭据，RESOLVED指已有异常及处置凭据，NONE包括未分配任务及已分配无异常任务。异常已处置不等于任务已送达。骑手只统计本人分配，负责人/仓管仅当前授权仓库。

响应新增summary{all,open,resolved,none,readAt}；all=open+resolved+none。计数不受当前筛选/分页影响，全部计数与当前页在同一RepeatableRead事务读取，非多页累计或前端估算。分页沿用出库时间+UUID稳定顺序，游标同样校验归属和当前筛选，不匹配404；任务处置后原OPEN游标可能失效，须刷新列表，不承诺跨请求固定快照。

UI使用真实API计数按钮、明确当前选中条件和作用域，切换条件清空旧页，不把读取失败伪装为空态；详情返回重新读同一筛选。列表显示异常类型及待处置/已处置标识，详情继续使用原授权处置流程；零匹配显示专用空态。没有UUID默认输入或演示统计。
