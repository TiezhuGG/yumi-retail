# S4 账号购物车与游客幂等合并

日期：2026-10-31。承接消费者会话基础；仅通过已有隔离开发身份验证，真实微信登录、真机、地址及结算未完成。下一切片为服务小区/楼栋白名单基础，再接消费者地址；具体真实小区资料仍待负责人提供，不代填经营范围。

## 切片与规则

- 游客继续使用本机草稿；已核验登录的详情加购进入本人账号购物车。账号与本机草稿分别展示，可以切换查看。退出登录不删除账号购物车。
- 登录后由用户确认把本机草稿合并到当前账号；同SKU数量相加，已有行勾选状态保持，新行沿用草稿勾选。不占库存、不锁价，无配送费或订单报价。
- 商品失效、缺货、超当前可用量、资料核验未知均保留条目及原数量。当前公开SKU核验后才计入参考小计；内部SKU编号不作为用户输入。
- 技术限制仍为最多50种SKU、总计200售卖单位、单行整数1–200，不是负责人确认的经营购买限额。合并后超限整笔拒绝，版本、回执和审计均不留半成品，不截断或丢行。
- 普通账号编辑使用全购物车版本，绝对数量/勾选和移除。旧版本409需重新读取；保存结果未知时暂停本页编辑，先读取最新购物车。详情加购未知时暂停本页重复加购，引导查看购物车。

## 幂等与恢复

合并编号为客户端UUID，仅作重试标识。发送前在同一个本机草稿键中原子保存`merge:{key,userId,items}`，items为独立快照；本机草稿写入入口冻结所有编辑/重置。服务端按当前会话用户+编号查回执，规范化SKU/标签并按SKU排序后摘要绑定内容；相同请求重放返回原结果，不同内容409。

响应未知、本机会话到期、页面关闭或清理草稿失败时，原快照和编号保留；恢复原账号后重试同一笔。其他账号不能接管待确认合并；登录资料被清除也不清除待合并草稿。只有权威确认拒绝（格式或技术限额）才解除待确认状态，原数量保持；500/网络未知/401不解除。成功后才清空同一笔本机草稿，再GET当前账号购物车，不用历史回执覆盖其他设备的新修改。

如果待合并元数据损坏或原稿与待合并快照不一致，阻止清除和再合并，保留原资料供核查；本轮不提供跳过此保护的自动重置入口。合并回执暂不自动过期清理，避免迟到重试重复累加；后续存储治理需另定安全窗口。

## 服务端、数据和兼容性

新增202610310005_consumer_carts：consumer_carts用户唯一/全局版本、consumer_cart_items用户+SKU唯一、consumer_cart_merges用户+key唯一/摘要/结果、consumer_cart_audits动作/版本/请求编号。全部外键归属消费者购物车。SKU引用刻意不设外键，以保留未知或已删除的游客引用；草稿名称/规格/单位为未核验标签，不读取隐藏商品资料补全，也不保存价格、库存或成本。

服务端每次事务先复验会话/用户启用、撤销、绝对到期和auth_version并加共享锁，再锁定本人购物车；所有写操作串行化该用户购物车。数量、版本、审计、合并回执同事务提交。当前会话只来自消费者Bearer，不接受userId/角色等输入，员工Cookie不能获得消费者身份；沿用本机开发会话开关及回环/隔离库限制，默认关闭开发登录。

本机沿用Docker Engine；未新增依赖/更改数据库或锁文件。本机Node24.22.0与精确目标24.22.1仍有一个补丁差异，pnpm会提示，本轮构建实测通过，未擅改版本要求。开发API已先停后迁移并重启，增量只新增表，不改旧库存/商品/会话。测试库在一次性schema应用完整迁移后清理，未向yumi_test/public应用本次增量迁移。其他环境升级先停消费者写入、迁移、生成客户端、构建再启服务，不清库回退。

## 实现的接口

所有接口均为`/api/v1/consumer/cart`下、消费者Bearer鉴权：

| 接口 | 行为 |
|---|---|
| GET / | 本人version/items，首次初始化空购物车；无价格/库存 |
| POST /items | version、skuId，当前公开且有货时加入1件/累加 |
| PUT /items/:skuId | version、quantity、selected，只能编辑已有本人条目 |
| DELETE /items/:skuId | body.version，移除本人条目 |
| POST /selection | version、skuIds、selected，最多50项 |
| POST /merge | items及Idempotency-Key；返回cart与合并时available/unavailable/excess/unknown检查 |

额外字段/查询参数400、未登录或会话失效401、本人没有该条目404、旧版本/合并超限/内容冲突409；加购缺货或不可用409。所有金额/库存仍需公开商品API实时读取。OpenAPI只描述已实现路由，未新增微信登录、地址或交易接口。
