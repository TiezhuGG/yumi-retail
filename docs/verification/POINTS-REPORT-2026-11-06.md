# 积分运营报表与对账（2026-11-06）

## 交付范围

运营后台→积分与快递→积分报表与对账。本轮交付只读报表、当前核对、筛选分页、账户流水查看和页面状态，不修改经营规则、余额、业务来源或审批流程，不导入/导出或自动调平。

- 本仓期间：按北京时间起止日期（含结束日，1至366天）统计发放、兑换、取消退回、售后退回、误发冲正五类实际入账流水的笔数/积分变动、每日增减与净额。未审批不计发放，扣减显示负数；类型只筛明细，汇总保持全部类型。
- 当前全历史业务核对：按原业务key及批准/发生状态检查账目、金额、用户、员工/消费者归属及兑换/退款指针，区分缺流水、内容不符、非入账状态却有流水；明细可按类型分页。尚未入账业务应记为0。
- 全局账户核对：逐户比较当前余额与累计流水，显示累计两端及不一致账户，差异可分页并打开原账户流水。全局账户余额不冒充本仓期间余额，抵消的正负差异仍逐户提示。
- 未归属业务流水：单独显示全局笔数/净额并提示核实，不误计为本仓发放，不在其存在时显示全部通过。外仓业务不混入本仓统计，全局余额保持全系统口径。
- 桌面分栏汇总与明细表，手机明细直接按卡片展示。刷新/失败清除旧统计，分页失败重试从首页重新读取；会话/权限/仓范围按原Workspace隔离。
