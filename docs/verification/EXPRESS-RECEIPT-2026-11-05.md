# 订单收货确认与状态筛选（2026-11-05）

范围：已发货本人快递订单明确确认收货、独立不可变事实、订单/我的/后台状态与筛选。验收案例包括未发货/他人禁止、确认弹窗取消、重复和响应丢失恢复、会话失效回滚、收货后仍可售后。

## 已完成

- 消费者订单分为全部、待发货、待收货、已完成、已取消；我的页展示待发货、待收货、已完成及售后入口。
- 订单详情“确认收货”弹窗说明全部商品和售后保留，取消弹窗不提交。成功显示确认时间；未知结果保留API/账号/订单隔离的原键，可核实结果，不伪造成功。
- 后台订单筛选/详情/快递面板同步用户确认状态与时间，无员工代确认按钮。
- receipt独立于原ACTIVE兑换单及EXPRESS_SHIPPED出库事实。无再次扣分/扣库存，无自动收货或售后结束；已完成订单仍可申请按件售后及反馈。
- 修正售后专用列表保留所有已发货（含收货后），分页游标因状态变化失效时重试从当前筛选重新读取。下拉刷新/触底分页保留，无刷新订单按钮。
- 手机卡片长单号与状态分行，避免状态被挤成单字换行；完成入口使用确认图标。
