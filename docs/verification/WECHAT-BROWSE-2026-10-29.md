## 微信工具实际验收（初次阻塞已解决）

本机安装Linux封装的微信开发者工具，工具版本 **2.02.2608080**，模拟器基础库 **3.17.5**。工具的新版技能接口多次返回授权超时；没有读取或修改其私有授权文件。安装包启动脚本会插入额外参数，标准CLI改用系统Node直接执行已安装CLI文件，未修改工具安装文件。

首次标准CLI查询明确返回 `IDE service port disabled`。负责人已回复“我会手动开启并授权”；随后标准CLI确认已登录并可打开本项目自动化会话。只使用当前已登录状态，不输出/保存登录票据，不上传小程序。自动化客户端miniprogram-automator0.13.0仅安装在 `/tmp/yumi-wechat-verify`，项目依赖和锁文件不变。

初次连接模拟器时没有商品，真实wx.request返回 `request:fail url not in domain list`；初始故障截图：[实际画面](WECHAT-BROWSE-INITIAL-2026-10-29.png)，仅作排查历史记录。

负责人随后确认已点击编译，并同意临时勾选开发工具“不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书”。确认后真实微信运行时请求本机API返回 **200**。但模拟器一度仍运行旧代码；仅清理本项目可重建的 `compile` 缓存并重新打开项目后，已读到本轮新说明和“找好物”入口，版本检查通过。没有清理登录/业务存储，没有修改工具安装文件或AppID。

最终在本项目自动化端口9421运行 `scripts/ui/verify-mini-wechat.cjs` **通过**：

- 真实API读取3个商品，模拟器首页名称与API一致；点击商品进入详情，名称及16.80元售价与API一致，下单按钮确实禁用；通过页面返回首页。
- 真实搜索可找到商品，不存在关键词显示空结果；首页、商品卡、详情、搜索及空态均已截图并实际查看。
- 模拟器内标明“UI合成”的503响应显示失败提示；修改输入框但未搜索后点击重试，仍恢复原失败查询的商品，未误用新输入。
- 合成第一页后，下一页503仍保留已有1件商品；再次重试追加第二件，最终显示2件，不覆盖已有页。错误和恢复的结果区截图均已查看。
- finally恢复真实wx.request并断开客户端；脚本最后重新加载真实首页并验证3个真实API商品。没有商品/库存写入、下单、支付或微信版本上传。

合成场景只在此次模拟器会话拦截wx.request，不修改API或数据库；截图商品名称明确带“UI合成”，不计为真实业务商品。首次按钮禁用断言发现SDK把属性返回为字符串“true”，脚本按实际属性类型验证后通过，未改变产品按钮行为。

验收结束按“临时”约定恢复 `project.private.config.json` 的 `setting.urlCheck=true`，该文件已恢复到本轮前内容；保留其他现有配置。随后关闭本项目自动化会话，并以普通模式重开项目。工具服务端口是负责人手动开启的设置，未自行撤销其授权。恢复域名校验后，本机HTTP地址仍会受到正常限制；需复验时再次由负责人选择本地开发设置，真机/生产必须配置可访问的合法HTTPS地址。

## 可复现方式

本地API默认 `http://127.0.0.1:3000/api/v1`。按README启动数据库/API；运行：

```sh
npm run test:mini-browse
npm run verify:mini:api
npm run build:mini
npm run verify:mini
```

工具CLI路径为 `/opt/apps/io.github.msojocs.wechat-devtools-linux/files/bin/resources/app.asar.unpacked/js/common/cli/index.js`；执行 `node <路径> islogin` 查询，`node <路径> auto --project <本项目绝对路径> --auto-port 9420` 打开本项目自动化。需负责人开启并授权工具服务端口，不提供自动改安全设置的脚本。

负责人确认本地开发域名设置并编译当前产物、打开本项目自动化后，从项目根运行（本轮实际端口9421）：

```sh
YUMI_MINI_WS=ws://127.0.0.1:9421 \
YUMI_MINI_AUTOMATOR_PATH=/tmp/yumi-wechat-verify/node_modules/miniprogram-automator \
node scripts/ui/verify-mini-wechat.cjs
```

脚本已完成上述端到端运行；先检查UI版本，再做真实读取，之后才临时模拟失败/分页。finally恢复wx.request并断开连接，脚本本身不关闭负责人窗口。等待选择器有界，不无限等待；模拟器滚动到结果区截图。工具/脚本检查通过仍不替代负责人产品UI确认。
