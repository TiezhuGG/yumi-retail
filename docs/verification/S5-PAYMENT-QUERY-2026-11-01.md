# S5 未知结果查询补偿任务与租约隔离基础 · 2026-11-01

接续上一轮支付尝试持久化。本轮为合成UNKNOWN证据安排持久化查询任务，交付租约抢占、过期恢复、旧持有者写入拦截、退避耗尽和后台任务区。适配器始终返回明确的合成UNKNOWN，不连接微信、不读取凭据，不入账、不退款、不释放库存。

## 实现与边界

保存合成UNKNOWN观察、安排唯一任务和员工审计同事务提交，重复观察不会重复排任务。迁移为已有UNKNOWN合成尝试回填RETRY任务及SCHEDULED历史，已知结果不回填。

领取以数据库时间和FOR UPDATE SKIP LOCKED完成，设置随机租约令牌并增加本轮领取次数。正常租约30秒，当前令牌未过期才允许完成；过期任务可由另一个Worker回收，旧持有者返回false且不再追加证据。领取只持有任务锁并先提交；完成按仓库共享锁→尝试锁→任务锁重读，API写入按兼容顺序锁定，避免任务锁等待尝试造成环路。

合成适配器只产生UNKNOWN。完成时证据事件、任务汇总及不可变任务历史同事务；晚期失败整体回滚，可用仍有效的原租约重试。同一租约不能二次有效完成。结果已变为关闭/成功/冲突时停止查询，不覆盖既有证据；100次证据上限也停止，任务DONE不代表交易已处理。

本轮最多领取3次，普通未知结果间隔1秒、5秒后重试，之后EXHAUSTED待核查；第三次失联租约过期同样耗尽，不无限回收。耗尽且仍UNKNOWN时，管理员可显式原键重新安排，重置本轮次数并保留历史；重试旧操作键不重复排任务或审计。这些是隔离环境技术参数，不是已经确认的正式支付重试/SLA规则。

## 模型、API与Worker

新增迁移202611010005_payment_query_labs：payment_query_lab_jobs每个合成尝试唯一且复合外键限定同仓，保存状态、次数、到期/租约、版本和创建时间；payment_query_lab_events保存不可变调度历史，关联有效完成产生的证据事件。约束固定状态/租约组合和0..3次数，触发器拒绝身份变更、删除任务、修改/删除历史及无对应版本历史的汇总更新；证据关联必须属于同一尝试。

API0.20.0，实际OpenAPI已导出。详情增加queryJob，不返回租约令牌/内部操作键；新增POST /api/v1/admin/payment-attempt-lab/run-query-cycle?warehouseId=UUID（空对象）和/:id/retry-query（仅{key:UUID}）。沿用员工Cookie、payment-readiness.read（默认SUPER_ADMIN）、启用仓库范围、Origin/CSRF及默认关闭的PAYMENT_NOTIFICATION_LAB_ENABLED。非法输入400、未登录401、无权403、记录不存在404、不满足重排条件/键冲突409、实验关闭503。

手动一轮只处理本仓至多一个到期任务，可能不是当前详情；无到期任务processed=false。第三次失联租约可只落耗尽历史而不执行查询。它是调度检查动作，不承诺旧请求响应重放；有效完成的副作用由租约和操作键保护。

自动Worker另需PAYMENT_QUERY_LAB_WORKER_ENABLED=1，默认0；同时必须PAYMENT_NOTIFICATION_LAB_ENABLED=1、PAYMENT_MODE=disabled、development/test、loopback本地yumi_dev/yumi_test。非法开关、生产、外部数据库或缺隔离条件启动拒绝。开启时每秒检查一轮合成任务，原有未支付订单超时内核继续运行；关闭时原有30秒周期保持。任务执行无HTTP适配器/URL/密钥参数，不能据此完成微信查单或真实支付补偿。
