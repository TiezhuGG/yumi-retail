## 实际完成

- 首发检查显示本仓待审核、待退货验收、待退积分申请数，三类与售后列表共用状态条件。驳回/撤销/退还完成不纳入未决待办；无需退货审核通过也进入待退积分。
- 点击入口进入“退货退积分”并应用状态筛选；原未知结果请求恢复仍优先处理，不能绕过原员工权限、CSRF和正式作业门禁。

- OpenAPI 0.63.0，新增4个统计字段。无迁移；前后端匹配构建，旧客户端可忽略新增字段。用户小程序本轮无需改版。
