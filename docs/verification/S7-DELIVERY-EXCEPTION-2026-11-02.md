# 合成配送异常上报与未决阻断 · 2026-11-02

本轮完成已接货、未合成送达任务的本人异常上报，三类固定合成原因：无法联系、拒收、包裹破损。每份分配最多一份不可变异常凭据；本轮异常均为未决，阻止新开始/送达动作。未提供处置、改派、退款或退回入库入口，未假定这些业务规则。负责人/仓管在本仓详情只读异常，骑手只处理本人任务。

POST /api/v1/delivery-lab/:id/report-exception?warehouseId=…仅接受key(UUID)、reason(UNREACHABLE/REFUSED/DAMAGED)。需delivery-lab.work、CSRF及本仓本人授权；相同原键/原因恢复成功结果，改原因/新键409，他人404，未接货或已送达409，默认关闭503。首次写入锁原任务，复核当前骑手/角色/仓库及出库快照。异常和审计同事务，报告与送达竞争只允许一方成功。已有原阶段凭据的恢复只读事实，不因异常丢失原键恢复能力。
