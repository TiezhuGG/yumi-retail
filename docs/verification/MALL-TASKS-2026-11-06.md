# 商城缺货与待处理提醒（2026-11-06）

## 范围与入口

运营后台→积分与快递→商城待办。本轮完成日常只读待办入口，沿用当前后台视觉和原业务权限。补齐实际查询、库存筛选/分页、状态定位以及加载/空/错误重试；没有改变兑换、上架、审批、退分或实物作业规则。正式阈值、超时标准、外部通知仍待确认与实现，不把它们标记完成。

- 缺货/低库存：使用与商城相同的库存公式，只统计当前可展示的上架兑换商品，0件为缺货，1至查看阈值为低库存。阈值默认5、可调整0至1000，只用于查询，不保存经营配置。按商品UUID分页，每页20条，条件在分页前应用。
- 八类待办：待快递发货、积分发放/冲正待审批、反馈待处理/处理中、退货退积分待审核、等待退回验收、待退积分；显示真实数量与最早时间。等待退回以批准时间、待退分以验收/无需退回的批准时间、反馈以最近更新时间计算，不将退货原申请时间当作全部阶段起点。
- 点击待办带实际筛选进入原页面；商品直接打开现有商品检查详情，继而使用已实现的维护入口。发放和冲正增加服务端状态筛选，未传时兼容旧客户端。发放对象/独立审批/预算/原键与库存约束不变。
- 请求失败清除旧统计；分页失败后重试从首页完整读取，避免将后页当作完整清单。账号范围沿用Workspace按身份/权限/仓库重建，未授权角色及已移除仓库绑定被服务端拒绝。
