# 小程序与运营后台图集样式实施

日期：2026-11-05。任务边界：将现有小程序 17 页、运营后台 31 个授权入口及其共用表单/详情/状态，对齐 `docs/design/yumi-ui-atlas/png`。未匹配的既有能力按同一视觉体系适配，不扩展未授权业务。

## 验收案例

1. 所有注册小程序页面在 390px、320px 可显示真实接口资料或明确状态，不横向溢出。
2. 所有后台授权入口在 1440px、390px 均可到达；桌面长导航独立滚动，手机导航可横向浏览。
3. 商品资料、规格、售价、条码、图片、分类、范围、报价、积分申请/预算、兑换商品、收货、盘点、隔离、纠错表单可打开、滚动与关闭，字段与原权限/校验保留。
4. 实际兑换订单详情、发货资料、配货打印、售后沟通、积分流水可读取；合成下单与发货资料只来自临时 schema 内的实际 API。
5. 小程序加载骨架、错误、重试恢复、搜索空结果，以及后台错误重试和空结果有单独截图。
6. 微信构建保留三个原生标签页，图标资源与新标题配置存在，构建产物用自带 React 运行时执行入口渲染。

## 实施内容

小程序采用奶白底、玉米黄主操作、深橄榄积分/会员卡和暖灰边框；统一标题、正文、地址与订单卡、输入、选择、数量控件、按钮、状态与错误提示。首页/目录使用相同兑换卡，缺少商品主图时仍明确标注包装示意。补齐六张本地标签图标、五个页面标题和共用加载骨架；整理“我的”页与购物车的信息层级。

后台统一深橄榄侧栏和线性图标、浅灰工作区、表格与筛选、状态标签及表单弹窗。修复侧栏内容过长时的可达性；兑换订单的阶段、查询、批量打印及表格合并到同一面板；售后列表和双栏处理详情分别成组；清除仓储老表单绕过主题的绿色行内按钮；打印预览同步暖灰配色，A4 分页规则不变。
