# 顾客停用、恢复与操作审计（2026-11-06）

## 范围与入口

运营后台→顾客管理→查看顾客→账号状态与操作记录。仅有效SUPER_ADMIN负责人可以在明确确认并填写原因后停用/恢复；运营人员只读历史，消费者/仓管不能调用。账号是全局身份，停用后无法登录及使用本人订单/售后入口；原积分、订单、预占与售后记录保留，后台按原权限继续办理已有业务，不自动取消、退款或清零。新积分发放申请及批准被停用状态阻断，原申请仍可核对、撤销或驳回。

## 实现与兼容

- 专用disable/enable动作，不接受enabled通用修改。读取stateVersion并确认，旧版本/相同状态拒绝覆盖；使用既有auth_version递增，停用及恢复均不复活旧令牌。
- 身份行锁与既有登录、交易和发放共享锁串行；不在身份锁后反向更新会话，避免昵称路径锁反序。原订单及后台退款不依赖顾客重新登录，保持既有权限和财务规则。
- 状态、不可变业务审计和幂等结果同事务；原因、前后状态、当时操作者姓名及实际DB动作时间可查，20条分页。原员工/动作/顾客键防重，原请求重放复验当前角色、会话、仓库，不能绕过撤权。
- 前端按员工/顾客保存未决原请求，跨刷新恢复同键核实；未知结果不会产生相反操作，明确冲突需要关闭/刷新后重确认。后台新发放入口随停用禁用；失去负责人权限不显示状态操作表单。
- API0.77.0，新增专用写接口与只读历史，顾客user兼容增加stateVersion。无迁移（仍62项），没有业务主库/真实顾客状态修改，没有改微信、支付或经营开关。
