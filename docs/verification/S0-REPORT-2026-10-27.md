## 5. 复现顺序

在项目根目录、启动Docker Desktop后：

```powershell
npm exec --yes --package=pnpm@10.28.2 -- pnpm install --frozen-lockfile
npm run setup:local
npm run db:up
npm run db:init
npm run db:generate
npm run db:migrate
npm run db:migrate:test
npm run build
npm run typecheck
npm run test:s0
npm run verify:mini
```

测试只清理本次生成的UUID夹具，不TRUNCATE、不reset、不删除开发数据。停止数据库用`npm run db:stop`，保留命名卷；不要随意使用down -v。
