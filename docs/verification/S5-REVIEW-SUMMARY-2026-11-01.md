# S5 合成核查只读概览 · 2026-11-01

完成当前授权仓库的核查总数/四类原因汇总、读取时间、卡片筛选与独立刷新，沿用现有绿白UI。真实支付、自动查询及实验写入配置不变；没有迁移或经营库演示数据。

## 边界与实现

- ALL是当前UNKNOWN/CONFLICT证据与EXHAUSTED/REVIEW任务的尝试并集；每尝试只计一次。四类原因可以重叠，不能相加；已知结果仍耗尽的尝试计入，备注不消除原因。NONE、已知且无异常任务不计入。
- 新GET `/api/v1/admin/payment-review-lab/summary?warehouseId=…`（OpenAPI0.26.0），严格只接受仓库参数。复用员工角色/权限、仓库归属/启用检查，默认写入关闭仍可读；不扩大任何动作权限。
- 单条SQL读取当前仓库尝试并LEFT JOIN唯一任务，所有COUNT FILTER共享MVCC语句快照。覆盖全量而非列表首20条，不JOIN事件/备注，不提供顾客、报文、租约、密钥、金额或真实支付统计。返回generatedAt为数据库语句开始时间。
- 概览与列表各次请求是实时快照，跨请求不承诺冻结一致。概览刷新不改筛选/详情/草稿；点击卡片沿用原列表筛选和草稿恢复。加载或失败清除旧统计，不显示假0；切仓后旧请求无效。
