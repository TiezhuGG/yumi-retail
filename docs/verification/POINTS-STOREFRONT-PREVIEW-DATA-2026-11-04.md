# 积分商城首发界面第一步：本机预览数据

Docker 项目 `yumi-points-preview` 使用仓库锁定的 PostgreSQL 17.11 镜像、独立数据卷和回环端口 55434。已应用全部迁移。预览 API 使用端口 3000，后台使用端口 5173。

本机忽略文件 `.local/points-preview.env` 保存连接配置及随机密码。后台使用 `admin` 登录，密码取其中的 `LOCAL_ADMIN_PASSWORD`。积分操作员为 `points.operator`，对应 `LOCAL_POINTS_OPERATOR_PASSWORD`。现有密码工具要求至少 12 位，使用随机密码满足校验。原业务库账号及审计记录保留在原库，当前预览后台使用新库的两个账号。

```powershell
docker compose --env-file .local/points-preview.env -p yumi-points-preview up -d --wait
node --env-file=.local/points-preview.env node_modules/pnpm/bin/pnpm.cjs --filter @yumi/database migrate
npm run build:server
node --env-file=.local/points-preview.env scripts/seed-points-preview.mjs
node --env-file=.local/points-preview.env apps/api/dist/main.js
```

在另一个终端运行 `npm run preview:admin:local`，后台使用已构建的 Web 产物。导入通过分类、商品、收货和上架业务操作准备演示数据，重复运行后核对 6 个分类、18 款兑换商品、360 件库存和 2 个启用员工账号。真实 API 已验证后台登录和公开兑换商品查询。

本切片交付数据和本机预览环境。下一项为统一底部导航、首页分类和常规商品卡片。真实微信和对外首发验收按受控环境手册接续。

第二项已接入微信原生底栏「首页 / 积分商城 / 我的」。首发首页以积分兑换为主，分类宫格与搜索直接打开积分商城并应用筛选，精选区读取后台排序的前六件可展示商品。首页与积分商城复用商品卡，状态来自库存和兑换开放配置。原入口中跳往底栏页面的操作改为切换标签。

小程序类型、代码规范和构建产物检查通过。390px 手机宽度浏览器预览连接本机 Docker 数据，验证三个入口、纸品分类三件商品、搜索洗衣液、查看详情，以及接口失败重试和空列表。截图为同源码浏览器预览，微信开发者工具和真机验收待做。没有 API 或数据库变更。下一项为微信登录引导和登录后返回原操作。

第三项增加可关闭的首页登录提示和独立微信登录页。兑换确认、积分、订单、收货地址等原登录入口保留页面栈，登录或取消后返回原页。积分页识别失效会话并提供重新登录入口，仍使用原会话核验、服务端授权和兑换提交确认。商品详情按实际兑换开放状态显示操作。没有 API 或数据库变更。

微信身份 PostgreSQL 集成 4 项、客户端会话 8 项和小程序产物保护 5 项通过。浏览器连接本机 API 和随机临时 schema，以合成微信凭证验证过期会话、取消、失败重试及返回积分页。微信平台及真机验收待做。下一项为重做「我的」。

第四项将「我的」重组为身份区、实际积分余额、兑换订单、常用服务和设置。兑换订单入口按全部、待发货、已发货和已取消打开列表，售后入口从已发货订单进入详情。规则区域读取实际寄送范围，设置提供微信隐私保护指引入口与退出登录。

消费者订单列表新增可选快递状态筛选，沿用账号归属及游标范围校验，无数据库迁移。8 项真实 PostgreSQL 发货回归通过，覆盖本人待发和已发筛选、他人隔离及非法值。390px 浏览器预览连接真实本机 API，验证游客和登录状态、实际余额、四个订单入口、售后、规则和退出。微信隐私保护指引及页面仍待真机验证。下一项为首发全流程回归。

第五项已完成本机首发全流程回归。浏览器串联同一笔订单，串行数据库复验 51 项通过，另有 9 项构建及发布保护检查。下一项进入真实受控环境联调。[验收与上线条件](POINTS-STOREFRONT-LAUNCH-REGRESSION-2026-11-04.md)

积分商城搜索移到顶部，分类使用微信原生横向滚动组件，移除余额登录按钮。「我的」采用头像与会员信息、深绿积分卡、四个订单入口及逐行常用服务。兑换确认和用户订单显示顾客用语，环境来源在运营后台保留。购物车页面及登录错误提示改用购物车用语。小程序类型检查、编译后渲染与 5 项构建保护检查通过。浏览器截图复验因自动审批用量限制未执行。
